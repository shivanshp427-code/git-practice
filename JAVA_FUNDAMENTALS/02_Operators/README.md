# Chapter 02: Operators & Expressions

Practicing operator precedence, type promotion in mixed expressions, and real-world math.

## What I Learned
1. **Type Promotion:** In expressions like yte + short + char, Java automatically promotes them to int. If double is involved, the whole expression becomes double.
2. **Explicit Casting:** How to forcefully cast expressions using (int) to avoid compiler errors.
3. **Precedence:** Parentheses () > Multiplicative * / % > Additive + -.

## Key Questions
- GSTBillCalculator.java: Takes cost of 3 items (pen, pencil, eraser) and calculates final bill with 18% GST.
- AverageOfThree.java: Calculates exact average of 3 numbers using double precision.
- TypePromotion.java: Example showing how mixed types behave in expressions.
- OperatorExpressions.java: Complex expression evaluation practice.
