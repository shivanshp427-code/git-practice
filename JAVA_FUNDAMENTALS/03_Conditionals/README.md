# Chapter 03: Conditionals & Decision Making

Programs practicing decision-making logic using if, else if, else, and logical operators (&&, ||, !).

## What I Practiced Here
1. **Multi-Condition Checks:** Checking divisibility rules (e.g. divisible by 5 and 3), finding if a number is a valid 4-digit number.
2. **Comparison Problems:** Finding the largest and smallest among 3 numbers (Big_of_3.java, Small_Of_3.java).
3. **Real-Life Logic:** Calculating profit/loss percentages, absolute value calculations, checking if given sides form a valid triangle.
4. **Coordinate Geometry:** Finding quadrant of a point on the Cartesian plane (QUADRANT_.java).

## Key Files
- Big_of_3.java - Nested and compound conditional checks
- 	riangle_or_not.java - Triangle inequality theorem logic
- profit_loss.java & profit_percent.java - Commercial math calculations
- QUADRANT_.java - 2D coordinate system condition mapping
