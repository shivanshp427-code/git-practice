# Chapter 08: Core Java Mixed Revision

Consolidating everything learned so far across conditionals, loops, patterns, and methods into a dedicated revision set.

## What I Practiced Here
1. **Number Theory & Factors:** Efficiently finding proper divisors and factor sums (`j * j <= i`), checking prime numbers up to `Math.sqrt(n)`.
2. **Conditionals & Range Validation:** Checking complex multi-variable conditions and logic flow.
3. **Loop Accumulations & Conversions:** Iterative factorial calculations and Decimal-to-Binary base conversions using powers of 10.
4. **Mixed Pattern Printing:** Nested loops with space calculation and running value increments.

## Files Overview
- `r16.java` - Sum of factors / divisor checks
- `r17.java` - Multi-variable conditional logic
- `r18.java` & `r19.java` - Digit processing and running loops
- `r20.java` & `r21.java` - Number pyramids with leading spaces

## Personal Takeaways
- Writing clean helper methods makes number problems (like prime and conversions) much easier to debug than stuffing everything inside `main`.
- Re-solving these after a few days helped test if the logic actually stuck in my head without looking at previous code.
